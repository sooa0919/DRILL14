# 새 떼 비행 애니메이션

`python main.py`로 실행합니다. Python과 `pico2d`, `PySDL2`, `transitions`가 필요합니다.
방향키로 소년을 이동하고 Space로 공을 발사하며 Esc로 종료합니다.

## 구현 방식

기존 `game_framework.frame_time`과 `game_world.update/render`를 그대로 사용합니다.
`play_mode.init`에서 생성한 새 10마리는 월드의 1번 레이어에 등록되며,
종료할 때 기존 `game_world.clear`로 함께 제거됩니다. 소년과 배경도 유지됩니다.

- `bird.py`: 이미지 공유, 프레임 선택, 시간 기반 이동, 방향별 그리기를 담당합니다.
- `flock.py`: 가로·세로 영역을 각각 10구간으로 나누고 구간 안의 위치를 무작위로
  선택합니다. 높이 구간을 섞어 줄지어 보이지 않도록 하고, 왼쪽 5마리·오른쪽
  5마리의 시작 방향도 섞습니다. 시작 프레임과 속도도 개체마다 달리합니다.
- 스프라이트는 918×506 이미지의 5열·3행 중 마지막 빈칸을 제외한 14칸입니다.
  가로·세로가 칸 수로 정확히 나누어지지 않아 각 경계를 정수 비율로 계산합니다.
  파일 위쪽에서 시작하는 행 번호를 pico2d의 아래쪽 원점 좌표로 변환합니다.
- 초당 14프레임으로 `frame = (frame + 14 × dt) % 14`를 계산합니다.
  소수 부분을 유지하고 그릴 때만 정수로 바꿔 프레임률에 따른 오차를 줄입니다.
- 이동 속도는 생성 시 초당 120~190픽셀 사이에서 정하며 표시 크기는 92×84픽셀입니다.
  중심의 이동 범위는 `[46, 화면 너비 - 46]`으로 정해 새 전체가 보이게 합니다.
- 이동 범위 길이를 `L`, 누적 이동 위상을 `s`라 하면
  `s = (s + 개체 속도 × dt) % (2L)`입니다. `s < L`이면 오른쪽,
  나머지는 왼쪽을 향하며, 위치는 각각 `왼쪽 경계 + s`,
  `왼쪽 경계 + 2L - s`입니다. 경계를 넘은 잔여 거리와 여러 차례의 왕복까지
  보존하므로 긴 프레임에도 화면 안에 머뭅니다. 왼쪽 비행은 수평 반전합니다.

왼쪽으로 출발하는 새는 초기 위치에 대응하는 왕복 위상의 뒤쪽 절반에서 시작해
첫 갱신에도 위치와 방향이 유지됩니다. 무작위 값은 생성할 때 한 번만 정하며,
각 새는 자기 속도로 부드럽게 왕복합니다. 군집 충돌이나 추종 행동은 사용하지 않습니다.

## 검증

`python -B -m unittest discover -s tests -v`로 테스트 11개를 실행합니다.
이미지 공유, 14개 유효 프레임, 날갯짓 주기, 좌우 반전, 경계의 잔여 이동,
정확한 끝점, 긴 경과 시간, 30·60·144 FPS의 동일 시간 결과, 10마리 배치,
모드 재진입 후 등록과 정리를 확인합니다. 왼쪽 출발 시 위치 연속성과 실제 이동,
서로 다른 높이·속도, 초기 양방향 분배도 검사합니다.

SDL 더미 드라이버에서도 실제 `main.py`를 실행해 101프레임을 렌더링했고,
매 프레임 10마리 존재, 양방향 비행, 종료 후 월드 정리를 확인했습니다.
이 검증은 그래픽 창을 띄우지 않는 자동 실행 검사입니다.
